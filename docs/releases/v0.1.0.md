# jpdev v0.1.0

The first release of the development kit.

## What it holds

- **`jpdev setup`**: clones with `gh repo clone` (or reuses a clone), makes the branch from a
  base, selects the toolchains the manifest names (node from nvm, go, python and its virtual
  environment), runs the manifest's setup steps under the caps and prints one summary block.
- **`jpdev check`**: runs the manifest's checks in order, each under its toolchain's cap, and
  prints one summary block: each check's name, pass or fail, the lines its `summary` regex
  matched and the first 40 lines of a failure. It stops at the first failure unless `--all`; the
  exit status is the number of failures.
- **`jpdev mutants`**: runs the manifest's mutants command with the given rows on a scratch copy
  of the clone and prints caught or not caught per row.
- **`jpdev record post`**: reduces the scratch and home paths to `<scratch>` and `<home>`,
  refuses to post when a local path remains or a line matches a pattern of the name list, and
  posts with `gh pr comment` or `gh issue comment`.
- **`jpdev env`**: the effective settings and where each came from.
- **The caps**: node under a resident-memory cap and timeout (`lib/rsscap.sh`), never
  `ulimit -v`; Go under the machine lock with `ulimit -v`, `GOFLAGS=-mod=mod`, a per-clone
  `GOCACHE` and `timeout`; python under `ulimit -v`.
- **The manifest**: `dev.json`, with `templates/dev.schema.json`; `jpdev check` validates against
  it with python3.
- **The public runner** `templates/check.sh`, which a repository vendors as
  `scripts/dev/check.sh` and which CI and contributors run with no caps.
- **The agent instructions**, `templates/AGENTS.md` and `templates/CLAUDE.md`, one text,
  generated and checked by `scripts/sync-agent-docs.sh`.
- **`templates/ci-check.yml`**, the CI step list.
- **`docs/policy.md`** and **`docs/adopting.md`**, with the agent repository's manifest as the
  worked example.

## Not in this release

A `jpdev release` command for the prepare, tag and gate chain; the adoption of the kit in each
repository.
